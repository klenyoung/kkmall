# KKMall 小电商平台 MVP 详细设计

本规格的正式详细设计已落地到：

- `docs/detail-design.md`

该详细设计以 `docs/prd.md` 和 `docs/overview-design.md` 为依据，覆盖：

- 数据库表结构。
- 订单、购物车、模拟支付、发货核心服务逻辑。
- 用户端和后台 API 请求/响应。
- 订单状态机。
- 错误码。
- 前端页面与路由守卫。
- 事务、并发和测试设计。

旧版详细设计中的真实支付、优惠券、积分、售后、复杂仓储等内容不属于当前 MVP 范围。后续实现和任务拆分以 `docs/detail-design.md` 为准。
