# 08 业财域 PRD

## 1. 功能概述

业财域提供平台经营数据的财务视角，包括交易流水、退款记录、销售报表、成本核算和促销 ROI 分析，支撑财务对账和经营决策。

---

## 2. 用户故事

| ID | 用户故事 | 优先级 | 验收标准（AC） |
|----|----------|--------|----------------|
| FI01 | 作为财务人员，我希望查看交易流水 | P1 | 1. 展示所有支付成功的交易记录<br>2. 支持按日期范围、支付方式筛选<br>3. 展示：订单号、支付单号、第三方流水号、金额、支付时间<br>4. 支持导出 Excel |
| FI02 | 作为财务人员，我希望查看退款记录 | P1 | 1. 展示所有退款记录<br>2. 支持按日期范围、退款状态筛选<br>3. 展示：退款单号、原订单号、退款金额、状态、退款时间 |
| FI03 | 作为财务人员，我希望查看销售报表 | P1 | 1. 支持按日/周/月/年查看<br>2. 展示：GMV、订单数、客单价、退款金额、净收入<br>3. 趋势图展示<br>4. 支持导出 Excel |
| FI04 | 作为财务人员，我希望查看商品毛利分析 | P2 | 1. 展示每个商品的销售额、成本、毛利、毛利率<br>2. 支持按分类汇总<br>3. 支持按毛利率排序 |

## 3. 业务流程

### 3.1 财务流水生成流程

```
支付成功事件（payment.success）
    ↓
业财域消费事件
    ↓
生成收入流水记录（类型：INCOME）
    ↓
退款成功事件（payment.refunded）
    ↓
生成退款流水记录（类型：REFUND）
    ↓
定时任务（每日凌晨）
    ↓
汇总当日流水，生成日报表
```

---

## 4. 报表说明

### 4.1 销售报表字段

| 字段 | 说明 |
|------|------|
| GMV | 成交总额（含退款订单） |
| 有效 GMV | 成交总额 - 退款金额 |
| 订单数 | 支付成功的订单数 |
| 退款订单数 | 退款成功的订单数 |
| 退款率 | 退款订单数 / 订单数 |
| 客单价 | 有效 GMV / 有效订单数 |
| 优惠总金额 | 优惠券 + 活动优惠 + 积分抵扣合计 |
| 净收入 | 有效 GMV - 优惠总金额 |

## 5. 界面要求

### 5.1 经营数据看板
- 顶部核心指标卡片（今日/本月）
- GMV 趋势折线图
- 订单数趋势图
- 热销商品 Top10
- 实时刷新（每5分钟）

### 5.2 财务报表页
- 日期范围选择器
- 汇总数据卡片
- 明细表格
- 导出按钮
