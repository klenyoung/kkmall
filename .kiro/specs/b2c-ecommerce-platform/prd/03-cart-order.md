# 03 购物车 & 订单域 PRD

## 1. 功能概述

购物车与订单域覆盖用户从选品到完成交易的核心购物链路，包括购物车管理、下单结算、订单全生命周期管理和售后申请。

---

## 3. 业务流程

### 3.1 购物车结算下单流程

```
用户进入购物车
    ↓
勾选商品 → 系统实时刷新价格和库存状态
    ↓
点击"去结算"
    ↓
进入结算页
    ├── 确认/选择收货地址
    ├── 选择优惠券（可选）
    ├── 使用积分（可选）
    └── 填写备注（可选）
    ↓
查看金额明细（商品总价 - 优惠 + 运费 = 实付）
    ↓
点击"提交订单"
    ↓
服务端校验：
    ├── 库存是否充足（同步锁定库存）
    ├── 优惠券是否有效
    └── 积分是否充足（锁定积分）
    ↓
校验通过 → 创建订单（状态：待付款）→ 跳转支付页
校验失败 → 返回结算页，提示具体原因
    ↓
支付页（30分钟倒计时）
    ├── 选择支付方式（支付宝/微信支付）
    └── 完成支付 → 订单状态：待发货
```

### 3.2 订单超时取消流程

```
订单创建（状态：待付款）
    ↓
30分钟倒计时
    ↓
超时未支付
    ↓
系统定时任务扫描（每分钟执行）
    ↓
订单状态变更为：已取消
    ↓
释放锁定库存
    ↓
释放锁定积分（如有）
    ↓
优惠券状态恢复为可用（如有）
    ↓
发送取消通知（站内信）
```

### 3.3 售后退款流程

```
买家申请售后（订单状态：已完成 → 售后中）
    ↓
创建售后工单
    ↓
客服审核（24小时内）
    ├── 审核通过
    │       ↓
    │   发起退款（订单状态：退款中）
    │       ↓
    │   支付平台处理退款（1-3个工作日）
    │       ↓
    │   退款成功（订单状态：已退款）
    │       ↓
    │   扣回对应积分（如有）
    │       ↓
    │   退货入库（如需）
    │
    └── 审核拒绝
            ↓
        工单关闭，订单状态恢复：已完成
        发送拒绝原因通知
```

## 4. 订单状态说明

| 状态 | 说明 | 可执行操作 |
|------|------|-----------|
| 待付款 | 订单已创建，等待支付（30分钟有效） | 去支付、**取消订单** |
| 支付中 | 已发起支付，等待支付结果（幂等中间态） | 查看支付状态（**不可取消**，需等待支付结果） |
| 待发货 | 支付成功，等待仓库发货 | 查看订单详情 |
| 已发货 | 仓库已发货，商品在途 | 查看物流、确认收货 |
| 已完成 | 用户确认收货或超时自动收货 | 评价、申请售后（**15天内**） |
| 已取消 | 用户主动取消或超时未支付 | 查看详情 |
| 售后中 | 用户申请售后，等待客服处理 | 查看售后进度 |
| 退款中 | 客服审核通过，退款处理中（幂等中间态） | 查看退款进度（**不可撤销**） |
| 已退款 | 退款成功 | 查看详情 |

## 5. 购物车数据说明

- **存储方式**：Redis Hash，Key 为 `cart:{userId}`，Value 为 SKU 快照
- **登录态合并**：用户登录时将 guest 购物车（`cart:guest:{deviceId}`）合并到用户购物车，相同 SKU 数量累加
- **价格快照**：加购时记录当时价格用于展示变价提示，结算时以实时价格计算
- **有效期**：登录用户购物车30天，未登录 guest 购物车7天

## 6. 界面要求

### 6.1 购物车页
- 顶部展示商品总数
- 每条商品展示：商品图片、名称、规格、单价、数量调节、小计、删除按钮
- 价格变动/库存不足/已下架商品有明显标识
- 底部固定：全选、合计金额、去结算按钮

### 6.2 结算页
- 顶部：收货地址（可切换）
- 中部：商品列表（不可修改数量）
- 优惠券选择区域
- 积分使用区域
- 备注输入框
- 底部固定：金额明细、提交订单按钮

### 6.3 订单列表页
- Tab 切换订单状态
- 每条订单卡片：商品缩略图、订单状态、金额、操作按钮
- 待付款订单显示倒计时

### 6.4 订单详情页
- 顶部：订单状态和进度条
- 收货地址信息
- 商品明细列表
- 金额明细
- 订单信息（订单号、下单时间、支付时间等）
- 底部操作按钮（根据状态动态展示）

## 7. 数据埋点要求

| 事件 | 触发时机 | 关键参数 |
|------|----------|----------|
| 加入购物车 | 用户点击加购 | skuId、来源页面、来源位置 |
| 购物车结算 | 用户点击去结算 | 商品数量、商品总价 |
| 订单提交 | 订单创建成功 | 订单号、商品数量、实付金额、是否使用优惠券/积分 |
| 订单取消 | 用户取消订单 | 订单号、取消原因 |
| 售后申请 | 用户提交售后 | 订单号、售后类型、原因 |
| 评价提交 | 用户提交评价 | 订单号、评分、是否含图片 |
