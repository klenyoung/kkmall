# 05 促销域 PRD

## 1. 功能概述

促销域提供多种营销工具，包括优惠券、满减活动、限时秒杀和积分规则，帮助运营人员提升转化率和客单价。

---

## 3. 业务流程

### 3.1 优惠券使用流程

```
用户进入结算页
    ↓
系统查询用户可用优惠券（过滤：未过期、未使用、满足订单条件）
    ↓
展示可用券列表（按优惠金额降序）
    ↓
用户选择优惠券
    ↓
系统实时计算优惠金额并更新应付金额
    ↓
用户提交订单
    ↓
服务端再次校验优惠券有效性（防止并发）
    ↓
下单成功 → 锁定优惠券（状态：已锁定）
    ↓
支付成功 → 优惠券状态变为：已使用
    ↓
订单取消 → 优惠券状态恢复：未使用
```

### 3.2 促销优惠计算规则

```
结算金额计算顺序：
1. 商品原价合计
2. 应用活动优惠（满减/秒杀价）
3. 应用优惠券抵扣
4. 应用积分抵扣（最多抵扣20%）
5. 加上运费
6. = 实付金额

优惠叠加规则：
- 满减活动 + 优惠券：可叠加
- 秒杀商品 + 优惠券：不可叠加（秒杀商品不参与优惠券）
- 多张优惠券：每笔订单只能使用一张
- 积分抵扣：可与所有优惠叠加，但最多抵扣实付金额的20%
```

### 3.3 秒杀活动流程

```
运营创建秒杀活动（设置商品、价格、库存、时间）
    ↓
活动开始前：商品详情页展示"即将开始"倒计时
    ↓
活动开始：商品以秒杀价展示，展示剩余库存
    ↓
用户下单（秒杀库存独立扣减，不影响正常库存）
    ↓
秒杀库存售罄：展示"已抢完"，正常库存仍可购买
    ↓
活动结束：恢复正常价格展示
```

## 4. 优惠券类型说明

| 类型 | 说明 | 示例 |
|------|------|------|
| 满减券 | 满足最低消费金额后减固定金额 | 满100减10 |
| 折扣券 | 按折扣率计算优惠金额 | 9折券（最多优惠50元） |
| 固定金额券 | 无门槛直接抵扣固定金额 | 无门槛5元券 |

## 5. 界面要求

### 5.1 我的优惠券页
- Tab：未使用 / 已使用 / 已过期
- 每张券卡片：面值（大字）、券名称、使用条件、有效期
- 即将过期（7天内）标红提示
- 未使用券底部有"去使用"按钮

### 5.2 结算页优惠券选择
- 展示可用券数量入口
- 弹出层展示可用券列表
- 不可用券置灰并说明原因
- 选中后展示优惠金额

### 5.3 活动页（秒杀/满减）
- 倒计时醒目展示
- 商品列表展示秒杀价和原价（划线）
- 剩余库存进度条
- 每人限购说明
