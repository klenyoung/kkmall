# 06 履约域 PRD

## 1. 功能概述

履约域负责订单从"待发货"到"已完成"的全过程管理，包括仓库发货操作、物流信息追踪、买家确认收货和超时自动收货机制。

---

## 3. 业务流程

### 3.1 发货流程

```
订单支付成功（状态：待发货）
    ↓
仓库人员登录后台，查看待发货订单列表
    ↓
拣货、打包
    ↓
选择快递公司，录入快递单号
    ↓
点击"确认发货"
    ↓
系统校验快递单号格式
    ↓
创建发货单，订单状态变为：已发货
    ↓
调用物流查询 API 初始化物流轨迹
    ↓
发送发货通知（短信：您的订单已发货，快递单号：XXXX）
    ↓
发送站内信通知
```

### 3.2 物流追踪流程

```
订单发货后
    ↓
系统定时任务（每小时）调用物流查询 API（快递100）
    ↓
更新物流轨迹数据
    ↓
检测到"已签收"状态
    ↓
不自动完成收货（等待买家主动确认或超时自动收货）
```

### 3.3 超时自动收货流程

```
订单发货后开始计时（15天）
    ↓
第12天：发送提醒通知（"您的订单将在3天后自动确认收货"）
    ↓
第15天：系统定时任务扫描
    ↓
订单状态变为：已完成
    ↓
发布 order.completed 事件
    ├── 用户域：发放积分
    └── 业财域：更新财务统计
    ↓
发送自动收货通知
```

---

## 4. 物流查询说明

- **接入服务**：快递100 API（主）/ 菜鸟物流（备）
- **支持快递公司**：顺丰、圆通、中通、申通、韵达、邮政、京东快递等主流快递
- **查询频率**：发货后前3天每小时查询一次，之后每4小时查询一次
- **数据缓存**：物流轨迹缓存30分钟，减少 API 调用次数

## 5. 界面要求

### 5.1 物流详情页（买家）
- 顶部：快递公司 Logo、快递单号（可复制）
- 物流状态：运输中/已签收
- 时间轴展示完整轨迹（最新在上）
- 底部：联系快递客服入口

### 5.2 待发货订单列表（仓库后台）
- 表格展示：订单号、下单时间、商品摘要、收货人、收货地址、操作
- 超时订单行背景标红
- 批量操作：批量发货
- 搜索：按订单号搜索

### 5.3 发货操作弹窗
- 快递公司下拉选择
- 快递单号输入框（支持扫码枪输入）
- 确认发货按钮

---

## 6. 数据埋点要求

| 事件 | 触发时机 | 关键参数 |
|------|----------|----------|
| 查看物流 | 买家点击查看物流 | 订单号 |
| 确认收货 | 买家主动确认收货 | 订单号 |
| 自动收货 | 系统超时自动收货 | 订单号 |
| 发货操作 | 仓库人员完成发货 | 订单号、快递公司、发货时效（下单到发货小时数） |
