# 07 仓储域 PRD

## 1. 功能概述

仓储域负责商品库存的全生命周期管理，包括入库、出库、库存查询、库存预警和盘点，确保库存数据准确，防止超卖。

---

## 3. 业务流程

### 3.1 库存锁定与释放流程

```
用户下单
    ↓
系统同步锁定库存（Redis 预扣 + DB 乐观锁）
    ├── 库存充足 → 锁定成功，订单创建
    └── 库存不足 → 返回错误，订单不创建
    ↓
支付成功
    ↓
锁定库存转为已扣减（总库存减少，锁定库存减少）
    ↓
订单取消/超时
    ↓
释放锁定库存（可用库存恢复）
    ↓
退货入库（退款且退货时）
    ↓
总库存和可用库存增加
```

### 3.2 库存预警流程

```
系统定时任务（每小时执行）
    ↓
扫描所有 SKU 的可用库存
    ↓
可用库存 ≤ 预警阈值
    ↓
查询是否已发送过预警（24小时内不重复发送）
    ↓
发送预警通知（站内信给运营人员）
    ↓
运营人员查看预警，安排补货
```

## 4. 库存状态说明

| 库存类型 | 说明 |
|----------|------|
| 总库存 | 仓库中实际存放的商品数量 |
| 锁定库存 | 已下单但未完成的订单占用的库存（待支付+待发货） |
| 可用库存 | 可以继续销售的库存 = 总库存 - 锁定库存 |

**前端展示规则：**
- 可用库存 > 10：正常展示，不显示具体数量
- 可用库存 1-10：展示"仅剩X件"
- 可用库存 = 0：展示"已售罄"，不可加购

## 5. 界面要求

### 5.1 库存管理列表（后台）
- 表格展示：SKU 信息、总库存、锁定库存、可用库存、预警阈值、操作
- 预警 SKU 行标红
- 支持搜索和筛选
- 操作：调整库存、查看流水、设置预警

### 5.2 库存流水页
- 时间范围筛选
- 操作类型筛选
- 表格展示流水记录
- 支持导出 Excel
