## PRD 文档规范说明

每个领域 PRD 包含以下标准章节：

1. **功能概述** — 本域核心能力说明
2. **用户故事** — 含优先级（P0/P1/P2）和验收标准（AC）
3. **业务流程** — 关键流程的步骤说明（流程图）
4. **业务规则** — 特殊规则和约束说明
5. **界面要求** — 关键页面的 UI 要求
6. **数据埋点要求** — 需要采集的用户行为事件
