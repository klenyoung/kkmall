# 中文优先 Hook

本项目默认使用中文进行需求沟通、设计澄清、spec 文档编写、任务拆分和交付说明。

## 触发规则

- 用户没有明确指定语言时，Agent 必须使用中文回复，即默认用中文回复用户。
- 新增或更新 `.kiro/specs/**` 文档时，主体内容必须使用中文，即默认用中文编写 spec 文档。
- 新增或更新 `docs/**`、`agents.md` 等项目文档时，主体内容必须使用中文。
- 代码注释优先使用中文，但只在确有必要时添加注释。

## 保持英文的内容

以下内容保持英文或原始格式：

- 类名、方法名、变量名、包名、组件名等代码标识符。
- API 路径、HTTP 方法、请求/响应字段名。
- 数据库表名、字段名、索引名和迁移文件名。
- 命令、环境变量、配置键、错误码、日志原文。
- 第三方库、框架、协议和产品的正式名称。

## 与 Spec 流程的关系

本 Hook 不跳过 spec-first 流程。所有新需求仍需按 `agents.md` 完成：

1. 需求澄清
2. 需求 Spec
3. 设计澄清
4. 设计 Spec
5. 任务拆分
6. 实现
7. 验证与文档更新
