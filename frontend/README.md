# KKMall Frontend

Vue3 + Vite + TypeScript + Ant Design Vue.

## Development

```bash
npm install
npm run dev
```

The dev server proxies `/api` to `http://172.23.86.146:8080` by default. Override with:

```bash
$env:VITE_API_PROXY="http://127.0.0.1:8080"
npm run dev
```

## Build

```bash
npm run build
```
