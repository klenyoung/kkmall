# 小电商平台 MVP 开发任务拆分

## 1. 当前开发策略

第一阶段先交付一个零依赖静态前端 MVP，用浏览器 `localStorage` 模拟后端数据，快速验证用户端购物闭环和后台发货闭环。

第二阶段再按 `docs/detail-design.md` 落地真实后端、数据库、API 和鉴权。

## 2. 第一阶段：静态前端 MVP

### 2.1 基础工程

- 创建 `frontend/index.html`。
- 创建 `frontend/styles.css`。
- 创建 `frontend/app.js`。
- 创建 `frontend/README.md`。
- 使用本地种子数据初始化分类、商品、SKU、管理员、用户、购物车和订单。

### 2.2 用户端功能

- 首页：搜索、分类入口、Banner、精选商品、商品流。
- 商品列表：分类筛选、关键词搜索、商品卡片。
- 商品详情：图片、价格、SKU、数量、库存、加入购物车。
- 登录：手机号 + 模拟验证码 `123456`。
- 购物车：数量修改、删除、库存/下架校验、合计。
- 结算：地址填写、商品金额、满 99 包邮、固定运费 10 元。
- 模拟支付：订单待支付 -> 已支付/待发货，扣减库存。
- 订单列表：按状态查看订单。
- 订单详情：商品明细、金额、地址、物流信息。

### 2.3 后台功能

- 后台入口：使用管理员手机号登录。
- 商品管理：新增商品、编辑商品、上下架、维护 SKU 价格和库存。
- 订单管理：查看订单列表、按状态筛选、订单详情。
- 发货管理：录入物流公司和物流单号，订单变为已发货。

### 2.4 UI/UX

- 主色参考天猫式电商红 `#FF0036`。
- 强搜索入口。
- 商品卡片流。
- 移动端底部固定关键操作。
- 后台采用高密度表格工作台风格。

## 3. 第二阶段：真实后端与数据库

- 按 `docs/detail-design.md` 创建 MySQL DDL。
- 实现 Spring Boot 3 后端模块：auth、catalog、cart、order、payment、fulfillment、admin。
- 替换前端 `localStorage` 数据层为 HTTP API。
- 实现 JWT 鉴权。
- 增加接口测试和主流程端到端测试。

## 4. 第一阶段验收

- 用户可以完成登录、浏览商品、加购、结算、模拟支付、查看订单。
- 后台可以新增/编辑/上下架商品。
- 后台可以对已支付待发货订单发货。
- 用户订单详情可以看到物流公司和物流单号。
- 页面中不出现非 MVP 功能入口。
